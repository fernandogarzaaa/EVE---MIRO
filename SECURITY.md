# Security policy

The security policy for the EVE engine in this repository lives in
[eve/SECURITY.md](eve/SECURITY.md). Start there for supported versions
and scope notes.

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/fernandogarzaaa/EVE---MIRO/security/advisories/new).
Please do not open a public issue for a vulnerability.

Include what you would need to reproduce it yourself: version or commit,
the component involved, and a minimal case. You should get an initial
response within a week.
